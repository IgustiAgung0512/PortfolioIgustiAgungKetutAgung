## 🚀 Cara Menjalankan Proyek Secara Lokal

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/IgustiAgung0512/PortfolioIgustiAgungKetutAgung.git
   cd PortfolioIgustiAgungKetutAgung
   ```

2. **Jalankan melalui Local Server**:
   * Gunakan ekstensi **Live Server** di VS Code, atau
   * Jalankan menggunakan server HTTP sederhana (Python):
     ```bash
     python -m http.server 5500
     ```

3. **Buka di Browser**:
   Akses `http://127.0.0.1:5500/index.html` pada browser favorit Anda.
